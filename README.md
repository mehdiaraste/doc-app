مدیریت کارها – نسخه PWA برای آیفون

محتویات:
- index.html: خود برنامه
- manifest.webmanifest: مشخصات نصب
- sw.js: پشتیبانی آفلاین
- icon-192.png و icon-512.png: آیکون برنامه

روش نصب روی iPhone:
1) پوشه را روی یک میزبان HTTPS منتشر کنید (مثلاً Netlify یا GitHub Pages).
2) لینک سایت را در Safari آیفون باز کنید.
3) دکمه Share را بزنید.
4) گزینه Add to Home Screen را انتخاب کنید.
5) در صورت نمایش گزینه Open as Web App، آن را روشن کنید و Add را بزنید.

نکته مهم:
- این نسخه اطلاعات را در حافظه همان مرورگر/دستگاه نگه می‌دارد و بین دستگاه‌ها خودکار همگام نمی‌شود.
- از بخش «خروجی پشتیبان» مرتب فایل پشتیبان بگیرید.
- برای حفظ داده‌ها، پاک‌کردن تاریخچه و داده‌های Safari ممکن است اطلاعات محلی برنامه را نیز پاک کند.
- برنامه در حال حاضر با 25 کار اولیه (6 انجام‌شده و 19 باز) شروع می‌شود.
